# Genius Typer — переключатель раскладки RU/EN, история буфера и локальная диктовка для Mac

[English](README.md) | **Русский**

**Genius Typer** — бесплатное приложение с открытым кодом для строки меню macOS: всё о наборе
текста для тех, кто пишет **по-русски и по-английски**.

- **Неверная раскладка исправляется сама**: «ghbdtn» после пробела становится «привет», «руддщ» —
  «hello». **Caps Lock переключает раскладку** мгновенно, как это часто настроено в Windows и Linux.
- **Ё на своих местах**: «еще» → «ещё», «Артем» → «Артём».
- **История буфера обмена** (⇧⌘C), как в Maccy.
- **Голосовой ввод** прямо на Mac: держите правый ⌥ и говорите — текст появится там, где курсор.
  NVIDIA Parakeet работает локально на Neural Engine; ничего не уходит с компьютера, если не
  выбрать облачный сервис.
- **Голосовые из Telegram** расшифровываются из кэша приложения Telegram (⌃⌥V).

Заменяет три приложения — **Caramba Switcher** (или Punto Switcher), **Maccy** и **TypeWhisper**
(или superwhisper, диктовку MacWhisper): один значок, один объект входа и ~23 МБ памяти. У каждой
части свой выключатель: ненужное можно отключить.

Интерфейс на **русском**. Строки идут через String Catalog (`GeniusTyper/Localizable.xcstrings`),
так что английский перевод можно добавить.

## Возможности

### Раскладка (Genius Switcher)

- **Caps Lock** переключает английскую и русскую раскладку при каждом нажатии (⇧ + Caps Lock —
  обычный Caps Lock). Сразу после автоисправления отменяет его; посреди слова перепечатывает буквы
  в другой раскладке; **двойное нажатие** переводит всю фразу с начала строки.
- **Автоисправление**: после пробела или знака препинания слово, которое как набрано — абракадабра,
  а в другой раскладке — настоящее слово, перепечатывается, и раскладка переключается. Caps Lock
  сразу после — отмена; ⇧+Пробел завершает слово без исправления. По умолчанию выключено в
  терминалах и редакторах кода; исключения по приложениям и по словам.
- **Ё**: словарь из ~107 000 форм, где ё нужна всегда (слова вроде «все/всё» не трогаются).
- Что считать словом, решает встроенная проверка орфографии macOS на обоих языках: без облака.
- Работает с любой английской и любой русской раскладкой из Системных настроек (ABC, U.S.,
  Русская, Русская – ПК…).

### История буфера обмена

- ⇧⌘C (можно сменить) открывает историю у курсора: поиск (в том числе набранный не в той
  раскладке), иконки приложений, предпросмотр; ⏎ вставляет, ⇧⏎ — без форматирования, ⌘1…9.
- Текст, форматированный текст, картинки и файлы; ограничение по размеру в МБ.
- Пропускает менеджеры паролей, приватные/временные типы буфера и сид-фразы криптокошельков.

### Диктовка (Диктант)

- **Правый ⌥** (можно сменить): удерживать — говорить, или нажать, чтобы начать, и нажать ещё раз,
  чтобы закончить. Esc отменяет.
- **Локально**: NVIDIA Parakeet TDT 0.6B v3 (25 европейских языков, определяются сами) через
  [FluidAudio](https://github.com/FluidInference/FluidAudio) на Neural Engine. Модель работает во
  вспомогательном процессе, который завершается после нескольких минут простоя, — память не занята.
- **Облако, по желанию**: Groq, OpenAI или любой OpenAI-совместимый `/audio/transcriptions` с
  вашим ключом (хранится в связке ключей).
- Небольшая плашка внизу экрана с уровнем микрофона, ё в надиктованном тексте, история с поиском
  и статистика (слова, слов в минуту, сэкономленное время).
- **Голосовые из Telegram**: новые голосовые из кэша официального приложения Telegram,
  расшифровываются локально и хранятся несколько дней.

## Лёгкое по устройству

Замеры на Apple Silicon, macOS 26, `scripts/profile.py`; память — как в «Мониторинге системы».
Подробности: [DICTATION-PROFILING.md](DICTATION-PROFILING.md), [MACCY-BASELINE.md](MACCY-BASELINE.md).

| | Genius Typer | Заменённые приложения |
|---|---|---|
| Покой: память | **23 МБ** (все три части) | Maccy 353–505 МБ, TypeWhisper ~113 МБ + виджет 30 МБ |
| Покой: процессор, пробуждения | **0.03%, 0/с** | Maccy 0.03%, ~100/с |
| Во время диктовки | ~17 МБ + помощник с моделью ~36 МБ, уходит после простоя | TypeWhisper держит модель в памяти |

Ничего не опрашивается по таймеру, кроме буфера обмена (`changeCount` дважды в секунду, как у
любого менеджера буфера).

## Приватность

- Клавиатура только прослушивается; буквы живут в памяти, пока набирается слово.
- В **журнале** (для улучшения распознавания) нет текста: раскладки, длины, решения, время и
  bundle ID приложения. **Журнал слов** хранит только исправленные слова (набрано → стало),
  30 дней, отключается; ничего из терминалов и редакторов кода.
- История буфера хранится локально в `~/Library/Application Support/GeniusTyper/`.
- Диктовка локальная, если не выбран облачный сервис. Звук не сохраняется.
- Менеджеры паролей исключены; поля защищённого ввода приложению не видны.

## Требования

- macOS 15 или новее. Для локальной диктовки желателен Apple Silicon (Neural Engine).
- Xcode и [XcodeGen](https://github.com/yonaskolb/XcodeGen) (`brew install xcodegen`).
- Английская и русская раскладки в Системных настройках → Клавиатура → Источники ввода.

## Сборка и установка

```bash
git clone https://github.com/ProteinR/GeniusTyper.git
cd GeniusTyper
./scripts/install.sh
```

Скрипт собирает Release, подписывает, ставит в `~/Applications/Genius Typer.app` и запускает.
Настройки → Основное показывают нужные разрешения и открывают нужные страницы Системных настроек:

- **Мониторинг ввода** — видеть нажатые клавиши (раскладка, Caps Lock, клавиша диктовки).
- **Универсальный доступ** — перепечатывать слова и вставлять текст (история буфера, диктовка).
- **Микрофон** — только когда включена диктовка.

На новой установке диктовка выключена: включите её в Настройки → Диктовка, тогда же скачается
локальная модель (~470 МБ) с Hugging Face.

### Подпись (чтобы разрешения не сбрасывались при пересборке)

Подписанных готовых сборок нет (нет аккаунта Apple Developer). Без постоянной подписи каждая
пересборка для macOS — новое приложение, и разрешения приходится давать заново. Чтобы этого
избежать, один раз создайте самоподписанный сертификат:

1. Связка ключей → Ассистент сертификации → Создать сертификат…
2. Имя: `Genius Typer Local Code Signing`, тип идентификации: «Самоподписанный корневой», тип
   сертификата: «Подпись кода».

`install.sh` найдёт его по этому имени (или укажите другое в `GENIUSTYPER_SIGN_IDENTITY`). Без
сертификата приложение подписано ad-hoc и всё равно работает.

Если разрешения «залипли» (выданы, а приложение всё просит):

```bash
tccutil reset ListenEvent com.dmemruk.GeniusTyper
tccutil reset Accessibility com.dmemruk.GeniusTyper
```

## Вопросы

**Другие языки?** Исправление раскладки сделано для одной английской и одной русской раскладки.
Диктовка понимает 25 европейских языков.

**А Caps Lock пропал?** ⇧ + Caps Lock по-прежнему включает его. Caps Lock на время работы
переназначается на F18 через `hidutil`; при выходе всё возвращается. Переключение по Caps Lock
можно выключить.

**Конфликтует с Maccy или Punto Switcher?** Держите запущенным один переключатель раскладки.
Maccy тоже занимает ⇧⌘C: закройте его или смените сочетание.
