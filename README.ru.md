**Genius Typer** — бесплатное приложение с открытым кодом для строки меню macOS: всё о наборе
текста для тех, кто пишет **по-русски и по-английски**. Аналог Punto Switcher и Caramba Switcher
для Mac, история буфера обмена как в Maccy и офлайн голосовой ввод (распознавание речи) в одном
нативном приложении, оптимизированном под Apple Silicon (M1, M2, M3, M4, M5).

- **Неверная раскладка исправляется сама**: «ghbdtn» после пробела становится «привет», «руддщ» —
  «hello». **Caps Lock переключает раскладку** мгновенно, как это часто настроено в Windows и Linux.
- **Ё на своих местах**: «еще» → «ещё», «Артем» → «Артём».
- **История буфера обмена** (⇧⌘C), как в Maccy.
- **Голосовой ввод** прямо на Mac: держите правый ⌥ и говорите — текст появится там, где курсор.
  NVIDIA Parakeet работает локально на Neural Engine; ничего не уходит с компьютера, если не
  выбрать облачный сервис.
- **Голосовые из Telegram** расшифровываются из кэша приложения Telegram (⌃⌥V).

Заменяет три приложения — **Caramba Switcher** (или Punto Switcher), **Maccy** и **TypeWhisper**
(или superwhisper, диктовку MacWhisper): один значок, один объект входа и ~23 МБ памяти. У каждой
части свой выключатель: ненужное можно отключить.

## Почему Genius Typer

- **Три приложения в одном — и легче любого из них**: 23 МБ памяти в покое на переключатель
  раскладки, историю буфера и диктовку вместе.
- **Ноль фоновой нагрузки**: 0 пробуждений процессора в секунду в покое (у Maccy ~100/с) — батарея
  не замечает приложения.
- **Офлайн распознавание речи на Neural Engine**: 10 секунд речи превращаются в текст за 0,08 с —
  примерно в 100 раз быстрее реального времени. Без подписки, без аккаунта, звук никуда не уходит.
- **Модель не сидит в памяти**: она живёт в отдельном процессе, который завершается через несколько
  минут простоя, — пока вы молчите, диктовка ничего не стоит.
- **Нативный Swift + AppKit**, универсальный бинарник (arm64 + x86_64): без Electron, Python и
  веб-вью. Основной бинарник — 6,6 МБ; движок распознавания — отдельный помощник.
- **Приватность по устройству**: что считать словом, решает встроенная проверка орфографии macOS,
  в журнале набора нет текста, менеджеры паролей и защищённый ввод не видны.
- **Бесплатно и с открытым кодом** (MIT); все цифры ниже воспроизводятся скриптами из репозитория.

Интерфейс на **русском**. Строки идут через String Catalog (`GeniusTyper/Localizable.xcstrings`),
так что английский перевод можно добавить.

## Возможности

### Раскладка (Genius Switcher)

- **Caps Lock** переключает английскую и русскую раскладку при каждом нажатии (⇧ + Caps Lock —
  обычный Caps Lock). Сразу после автоисправления отменяет его; посреди слова перепечатывает буквы
  в другой раскладке; **двойное нажатие** переводит всю фразу с начала строки.
- **Автоисправление**: после пробела или знака препинания слово, которое как набрано — абракадабра,
  а в другой раскладке — настоящее слово, перепечатывается, и раскладка переключается. Caps Lock
  сразу после — отмена; ⇧+Пробел завершает слово без исправления. По умолчанию выключено в
  терминалах и редакторах кода; исключения по приложениям и по словам.
- **Ё**: словарь из ~107 000 форм, где ё нужна всегда (слова вроде «все/всё» не трогаются).
- Что считать словом, решает встроенная проверка орфографии macOS на обоих языках: без облака.
- Работает с любой английской и любой русской раскладкой из Системных настроек (ABC, U.S.,
  Русская, Русская – ПК…).

### История буфера обмена

- ⇧⌘C (можно сменить) открывает историю у курсора: поиск (в том числе набранный не в той
  раскладке), иконки приложений, предпросмотр; ⏎ вставляет, ⇧⏎ — без форматирования, ⌘1…9.
- Последние записи есть и в меню по левому клику на значке: наведите на «История буфера» — список
  с поиском; клик копирует запись, при наведении рядом открывается её предпросмотр.
- Текст, форматированный текст, картинки и файлы; ограничение по размеру в МБ.
- Пропускает менеджеры паролей, приватные/временные типы буфера и сид-фразы криптокошельков.

### Диктовка (Диктант)

- **Правый ⌥** (можно сменить): удерживать — говорить, или нажать, чтобы начать, и нажать ещё раз,
  чтобы закончить. Esc отменяет.
- **Локально**: Parakeet Ultra (дообученная Moondream модель NVIDIA Parakeet TDT 0.6B v3, по
  умолчанию) или сама Parakeet v3 (25 европейских языков, определяются сами) через
  [FluidAudio](https://github.com/FluidInference/FluidAudio) на Neural Engine. Ultra так же быстра и
  заметно точнее (на митингах автора и уроке английского там, где модели расходились, Whisper был на
  стороне Ultra 216 раз, на стороне v3 — 71), на диске ~630 МБ вместо ~470 МБ. Модель работает во
  вспомогательном процессе, который завершается после нескольких минут простоя, — память не занята.
- **Облако, по желанию**: Groq, OpenAI или любой OpenAI-совместимый `/audio/transcriptions` с
  вашим ключом (хранится в связке ключей).
- Небольшая плашка внизу экрана с уровнем микрофона (шкала подстраивается под микрофон и
  обстановку и запоминается для каждого микрофона), ё в надиктованном тексте, история с поиском
  и статистика (слова, слов в минуту, сэкономленное время).
- **Голосовые из Telegram**: новые голосовые из кэша официального приложения Telegram,
  расшифровываются локально и хранятся несколько дней или всегда; по ним есть поиск, каждый текст
  можно скопировать или удалить, в том числе в истории в настройках.

## Сделано под Apple Silicon

Замеры на Mac с чипом M, macOS 26: `scripts/profile.py`, `top`, `heap`, `leaks` и собственные
режимы `--…-test`; память — как в «Мониторинге системы». Подробности:
[DICTATION-PROFILING.md](DICTATION-PROFILING.md), [MACCY-BASELINE.md](MACCY-BASELINE.md).

| | Genius Typer | Заменённые приложения |
|---|---|---|
| Покой: память | **23 МБ** (все три части) | Maccy 353–505 МБ, TypeWhisper ~113 МБ + виджет 30 МБ (выбран облачный движок, без локальной модели) |
| Покой: процессор, пробуждения | **0.03%, 0/с** | Maccy 0.03%, ~100/с |
| Копирование текста раз в секунду | **0.95% процессора** | Maccy 17.3% |
| Картинка 800×600 раз в 2 с | **1.5%, 37 МБ** | Maccy 12.6%, 546 МБ |
| Во время диктовки | ~17 МБ + помощник с моделью ~36 МБ, уходит после простоя | — |
| Утечки после 3 кругов стресс-теста | наших нет (`leaks`), память не растёт | — |

Maccy замерялся таким, каким им пользовались, а не чистой установкой: версия 2.7.1 после четырёх
дней работы с настоящей историей, так что его память зависит от этой истории. Строки с
копированием — одни и те же скрипты для обоих приложений.

**Локальная диктовка** (NVIDIA Parakeet TDT 0.6B v3, CoreML на Neural Engine):

| | Время |
|---|---|
| Загрузка модели (из кэша) | 0,17–0,27 с — пока вы уже говорите |
| 7 с речи | 0,07 с |
| 10 с речи | 0,08 с (0,35 с вместе с запуском помощника) |
| 20,7 с речи | 0,28 с |
| Голосовое из Telegram, 9 с | 0,46 с вместе с запуском модели |

**За счёт чего так легко:**

- Модель речи работает на **Neural Engine** через CoreML, а не на процессоре или видеокарте, и в
  отдельном процессе: освобождённую CoreML память работающий процесс системе не возвращает, поэтому
  помощник просто завершается (54 МБ → 15–17 МБ после диктовки).
- Ничего не опрашивается по таймеру, кроме буфера обмена (`changeCount` дважды в секунду, как у
  любого менеджера буфера). Таймеры есть только пока на экране плашка диктовки.
- Плашку записи рисуют слои **Core Animation**, 60 кадров в секунду: каждая полоска — слой, у
  которого меняется рамка, линия — один путь за кадр; view не перерисовывается (~3% процессора,
  линия при отрисовке во view брала 9.5%); WindowServer — в пределах ~1.5% от обычного.
- Кадры анимаций — сырые пиксели, сжатые Apple **LZFSE**, отображены в память и распаковываются по
  одному: 0,15 мс на кадр против ~1 мс у PNG.
- Словарь ё (~107 000 слов) отображён в память, поиск двоичный: без кучи.
- Окна строятся при открытии и освобождаются при закрытии; без SwiftUI `Charts`/`Canvas` и
  системного `Toggle`, который один занимал ~100 МБ графической памяти.

## Приватность

- Клавиатура только прослушивается; буквы живут в памяти, пока набирается слово.
- В **журнале** (для улучшения распознавания) нет текста: раскладки, длины, решения, время и
  bundle ID приложения. **Журнал слов** хранит только исправленные слова (набрано → стало),
  30 дней, отключается; ничего из терминалов и редакторов кода.
- История буфера хранится локально в `~/Library/Application Support/GeniusTyper/`.
- Диктовка локальная, если не выбран облачный сервис. Звук не сохраняется.
- Менеджеры паролей исключены; поля защищённого ввода приложению не видны.

## Требования

- macOS 15 или новее. Для локальной диктовки желателен Apple Silicon (Neural Engine).
- Xcode и [XcodeGen](https://github.com/yonaskolb/XcodeGen) (`brew install xcodegen`).
- Английская и русская раскладки в Системных настройках → Клавиатура → Источники ввода.

## Сборка и установка

```bash
git clone https://github.com/ProteinR/GeniusTyper.git
cd GeniusTyper
./scripts/install.sh
```

Скрипт собирает Release, подписывает, ставит в `~/Applications/Genius Typer.app` и запускает.
Настройки → Основное показывают нужные разрешения и открывают нужные страницы Системных настроек:

- **Мониторинг ввода** — видеть нажатые клавиши (раскладка, Caps Lock, клавиша диктовки).
- **Универсальный доступ** — перепечатывать слова и вставлять текст (история буфера, диктовка).
- **Микрофон** — только когда включена диктовка.

На новой установке диктовка выключена: включите её в Настройки → Диктовка, тогда же скачается
локальная модель (~470 МБ) с Hugging Face.

### Подпись (чтобы разрешения не сбрасывались при пересборке)

Подписанных готовых сборок нет (нет аккаунта Apple Developer). Без постоянной подписи каждая
пересборка для macOS — новое приложение, и разрешения приходится давать заново. Чтобы этого
избежать, один раз создайте самоподписанный сертификат:

1. Связка ключей → Ассистент сертификации → Создать сертификат…
2. Имя: `Genius Typer Local Code Signing`, тип идентификации: «Самоподписанный корневой», тип
   сертификата: «Подпись кода».

`install.sh` найдёт его по этому имени (или укажите другое в `GENIUSTYPER_SIGN_IDENTITY`). Без
сертификата приложение подписано ad-hoc и всё равно работает.

Если разрешения «залипли» (выданы, а приложение всё просит):

```bash
tccutil reset ListenEvent com.dmemruk.GeniusTyper
tccutil reset Accessibility com.dmemruk.GeniusTyper
```

## Чем заменяет

Ищете **Punto Switcher для Mac**, замену **Caramba Switcher**, автоматический переключатель
раскладки для macOS, бесплатную замену **Maccy** или офлайн замену **superwhisper / MacWhisper /
Wispr Flow / TypeWhisper** для голосового ввода? Genius Typer делает всё это в одном приложении в
строке меню, бесплатно и без отправки текста или голоса куда-либо.

| Нужно | Обычно | Genius Typer |
|---|---|---|
| Исправить текст, набранный не в той раскладке (RU ↔ EN) | Punto Switcher, Caramba Switcher | Автоисправление + Caps Lock |
| Переключать раскладку Caps Lock | Системная настройка, Karabiner-Elements | Встроено, мгновенно, с отменой |
| История буфера обмена | Maccy, Paste, Raycast | ⇧⌘C, поиск в любой раскладке |
| Голосовой ввод, диктовка | superwhisper, MacWhisper, Wispr Flow, TypeWhisper | Parakeet локально на Neural Engine или Groq/OpenAI |
| Расшифровка голосовых из Telegram | Telegram Premium, боты | Локально, из кэша Telegram |

## Вопросы

**Работает на Mac с Intel?** Да, бинарник универсальный; но быстрой локальной диктовке нужен Neural
Engine Apple Silicon, на Intel лучше облачный сервис.

**Бесплатно? Нужен интернет?** Бесплатно, лицензия MIT. Интернет нужен только чтобы один раз
скачать модель речи (~470 МБ); дальше всё работает офлайн.

**Другие языки?** Исправление раскладки сделано для одной английской и одной русской раскладки.
Диктовка понимает 25 европейских языков.

**А Caps Lock пропал?** ⇧ + Caps Lock по-прежнему включает его. Caps Lock на время работы
переназначается на F18 через `hidutil`; при выходе всё возвращается. Переключение по Caps Lock
можно выключить.

**Конфликтует с Maccy или Punto Switcher?** Держите запущенным один переключатель раскладки.
Maccy тоже занимает ⇧⌘C: закройте его или смените сочетание.
